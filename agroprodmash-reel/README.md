# Агропродмаш 2026 — рилс глазами посетителя

Вертикальный ролик 1080×1920, ~57 с, 30 fps. Склейки строго в бит трека 128 BPM.

## Как собран

1. `tools/make_music.py` — синтезирует трек под структуру монтажа (хук → подводка → дроп → главы → финал).
   Музыка сгенерирована кодом, поэтому проблем с авторскими правами нет.
2. `tools/cut.py` — монтажный лист (EDL): из каждого исходника берётся 1–2 лучших секунды,
   режется по сетке битов, цветокорректируется и склеивается в `assets/base.mp4`.
3. `index.html` — композиция HyperFrames поверх нарезки: кинетические титры, главы,
   панчи и вспышки на склейках, whip-переходы между главами, шкала прогресса, финальный CTA.

Исходники лежат в `../footage/agroprodmash`.

## Пересобрать

```bash
npm run music    # assets/music.wav
npm run cut      # assets/base.mp4 (в git не хранится, >100 МБ)
npm run check
npm run render   # renders/agroprodmash-reel.mp4
```

Нужны Node.js 22+, FFmpeg и Python 3 с numpy и scipy.

Поменять текст — массив `CAPS` в `index.html` (тайминг в битах).
Поменять кадры — список `EDL` в `tools/cut.py`; если меняется длина шота,
обновите `SHOT_BEATS` в `index.html`.
